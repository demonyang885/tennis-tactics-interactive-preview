# RallyPath v0.5.0 介面改版交付

本輪以 v0.4.0 已接受的二段跑位試作為基礎，將其收斂為 iPhone／iPad 優先的 Web 介面。公開站原為 v0.3.7，因此發布差異亦包含此前已接受、只在獨立測試站提供的四種開局、180 度視角、可選二段跑位與物件提示。這些是前期試作的整合；本輪 UI 改版沒有修改 `src/board/model.ts`、渲染座標、戰術判定或 AI signals。

## 頁面前後對照

| 頁面 | 改版前 | v0.5.0 |
| --- | --- | --- |
| 首頁／画板 | 預覽首頁再進入編輯器 | 打開即為可編輯畫板；品牌和版本固定，純圖示導航與編輯工具分離 |
| 畫板操作 | 單一底部操作列，展開常用項 | 玻璃工具列、突出播放按鈕；展開撤銷、重做、調換、拍次、設定；四種站位仍直接選 |
| 發球／接發 | 使用開局選項替換當前站位 | 頂部 segmented control；兩個模式引用不同畫板，各自保存；切換先保存當前編輯 |
| 找打法 | 由選單进入完整列表 | 底部圖示打開半屏 sheet；選中後另建「初始站位＋第一拍」，保留原畫板；完整戰術庫仍可瀏覽 |
| 畫板庫 | 從首頁或編輯器進入 | 固定三個純圖示導航入口與主畫板位置一致；保留搜尋、用途、刪除確認及資料恢復 |
| 拍次 | 純文字列表與編輯 | 短標籤 chip，可標記關鍵拍；沿用既有 label 儲存，支援撤銷、備份及刷新 |
| 設定／彈層 | 原有主題與菜單 | 淺／深色玻璃控制層，拖曳關閉；分區開關仍明確顯示「分区已开／分区已关」 |
| 文字備註 | 原生鍵盤與簡易編輯 | 保留原生輸入，攔截開啟編輯器時的點擊穿透；不恢復已停用的「發現筆記」 |

## 檔案

- `src/Prototype.tsx`：直接進入畫板、三入口導航、半屏打法選單、模式切換、關鍵拍、觸控及返回／刪除後導航邊界。
- `src/prototype.css`：玻璃材質、深淺色、安全區、44 px 目標、8 px 間距、iPad 比例、降低透明度／動態效果及高對比。
- `src/ui/BoardIcon.tsx`：2 px 圓端線性功能圖示。
- `src/board/workspace.ts`：只保存發球／接發畫板 ID 的介面偏好及可選觸覺回饋；內容仍使用原有儲存層。
- `tests/*`：遷移舊首頁入口，保留資料安全及 B/C/D 驗收；增加直接開啟、雙模式、iPad、主題、關鍵拍及 Dock 對齊檢查。
- `docs/archive/qa/ios-workspace/`、`docs/archive/retired-home-ui-2026-10-03/`：保留已退役首頁的視覺測試及退役理由，不再把舊首頁設計當成新介面的驗收標準。
- `docs/product/IOS_DOCK_REVIEW.md`：獨立 UI 審查與 Apple HIG 來源、截圖判讀及限制。
- `package.json`、`package-lock.json`、`CHANGELOG.md`、`AGENTS.md`：版本 0.5.0、變更記錄及本輪方向。`version.json` 在建置時使用版本與實際提交 SHA 產生。

## 驗收方法

| 項目 | 環境／動作 | 驗證範圍 |
| --- | --- | --- |
| iPhone／iPad 佈局 | Chromium 手機 320／390 寬；平板 820×1180、1180×820；另以 WebKit 執行主要工作區操作 | 無橫向溢出、主要工具目標與間距、旋轉視口、固定 Dock、畫板重開 |
| 深淺色 | 切換瀏覽器色彩偏好、逐張檢視畫板／工具／設定／打法／畫板庫 | 控制層同步切色；同一畫板 canvas 像素不因控制層主題改變 |
| 降低透明度／高對比 | Chromium CDP 媒體偏好模擬 | computed style 為實色、backdrop-filter none、邊框 2 px |
| B 多拍 | 真實拖曳第一拍、接球跑位、回球、播放及刷新 | 實際拍數、內容保存；另保留前期二段跑位回歸 |
| C JSON | 瀏覽器下載、解析、重新上傳 v1／v2 備份，輸入壞 JSON | 有效 JSON、導出不另存副本、往返一致、壞資料可見錯誤且原資料保留 |
| D1–D6 | 版本、刪除確認、分區狀態、練習入口場地、重開球路、對象刪除名稱 | 逐項沿用 `issue11-editor`、`version-ui`、刪除與相關回歸 |
| 儲存邊界 | 模擬配額不足、失敗恢復、跨分頁競爭、刪除後返回／刷新 | 不覆寫新版、不復活已刪資料、不在單純瀏覽時新增空白畫板 |

自動化、建置與部署的最終結果以本版本 GitHub PR／Actions 和公開 `version.json` 為準。實體 iPhone／iPad Safari 的鍵盤、系統字級、VoiceOver、動態網址列及主觀流暢度仍由用戶真機驗收；瀏覽器模擬不等同原生 iOS 認證或 60 fps 證明。
