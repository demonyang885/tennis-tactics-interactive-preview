狀態：產品負責人於 2026-09-30 明確批准跳過未完成的實體裝置與青少年試用關卡，直接合併發布。這是**帶已知風險的發布決策**，不是聲稱這兩項驗收通過。以 `main` 成功部署及線上 `version.json` 為最終上線證據。

## 本版核心

孩子從自己的畫板畫出或回顧一分，按需要進入既有分類戰術庫，或選擇六項固定技能之一；第一階示範在同一戰術畫板上播放。「練這個」返回原畫板並保存技能關聯。刷新、重開、另存和可編輯備份要維持正確 boardId；純看模板或技能不生成草稿。

可從指定拍次另畫一條試法；文字備註直接留在球場，舊獨立發現只在畫板管理按需唯讀。戰術庫是一頁豎向列表，以按需錨點目錄抵達分段，縮圖呈現核心球路，導航不使用裝飾性右箭頭。首頁保持以畫板為中心，不恢復舊訓練三卡。

## 下一輪開發順序

1. **發布後守護。** 核對 GitHub Pages 部署 run、線上 `version.json` 的產品名、`0.3.0` 與 main 提交；記錄可以回滾的上一版提交。若出現無法進入畫板、存檔錯關聯或資料丟失，先停止擴充並修復。
2. **真機驗收。** 在 iPhone Safari 與 iPad Safari 直／橫向完成畫線、示範、選技能返回、刷新與關頁重開、備註原生鍵盤、備份／匯入。記錄裝置、系統、操作、結果和截圖；優先修資料及入口問題。
3. **青少年獨立試用。** 讓孩子不靠口頭教學完成畫、選、回來，並用自己的話說明技能／打法與原分的關係；再看訓練後是否能回來找出這個選擇。不要把成人代操或點擊率當作理解證據。
4. **網球內容校準。** 先核對「受壓回深爭取回位」「短球打深後跟進」「斜線調動再變線」三個既有情境與六項技能第一階，逐一說清何時用、想換來什麼、練哪一點、何時改打法；請懂青少年教學的人複核。不先增加模板數量。
5. **再定下一版。** 收攏 #7、#8 的實際結果，修復阻斷後重跑完整回歸。若孩子理解和使用證據支持，再討論少量對手應變分支；AI 自動建議、課程／打卡、雲同步、社區不在本輪。
