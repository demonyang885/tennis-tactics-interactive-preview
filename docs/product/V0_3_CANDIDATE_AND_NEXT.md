# RallyPath v0.3 候選版與後續開發

狀態：候選提交，不等於正式發布。正式站與 `main` 仍為 v0.2.0，直到本版通過下列關卡並獲產品負責人批准。

## 候選版交付

從孩子自己畫的一分出發：保留原畫板，按需要找一個相關打法或六項固定技能之一；技能可看第一階畫板示範，再用「練這個」返回原畫板。刷新、重開、另存和可編輯備份要維持正確關聯。找打法可從指定拍次另畫一條試法；文字備註直接留在球場，舊獨立發現僅在畫板管理按需唯讀。戰術庫為一頁豎向列表、按需錨點目錄，導航列沒有裝飾性右箭頭。

候選版保留同一瀏覽器自動保存與手動可編輯備份，不宣稱跨裝置同步；單純查看模板／技能不生成個人草稿，不把選技能當作完成訓練。

## 本次已知證據與未完成項

- 本機 `verify:release`：284 項瀏覽器回歸、6 項媒體核心、28 個受保護 runtime 檔、型別／內容、建置、Sites 4 項及 Pages 3 項通過。這是自動化證據，不是真機或孩子的理解證據。
- 真實 iPhone／iPad Safari 的原生鍵盤、手指／Pencil、橫直向、關頁重開、分享仍待驗；先前雙頁頭／返回閃動須在原手機刷新後複核。
- 青少年獨立完成「畫一分 → 找打法或選技能 → 返回並找回」尚未測；訓練或比賽後的下一次回訪尚無證據。
- `localStorage` 的跨 key／跨分頁寫入不是原子交易。已有續接、故障提示、匯出與多項競態回歸；完全損壞的續接記錄及無備份舊版刪除仍有人工恢復風險。發布說明必須保留這項限制。
- 主 JS 建置仍有超過 500 kB 的性能警告；未量測真機啟動前不憑警告重寫架構，也不把警告隱藏。

## 後續工作順序

1. **固定候選提交與 CI。** 只在短期分支開 PR；核對差異沒有回退 v0.2 發布收尾文件，不把本機路徑、局域網網址或 QA 截圖批量公開。CI 全綠後保留候選 SHA，`main` 不因 PR 存在而更新。
2. **真機任務。** 用同一候選版在 iPhone Safari 與 iPad Safari 直／橫向完成建板、畫線、打開示範、選技能返回、刷新與關頁重開、文字備註原生鍵盤、備份／匯入。記錄裝置、系統、觀察和阻斷畫面；先修資料丟失、錯關聯和不可達入口。
3. **孩子獨立試用。** 孩子不靠口頭教學完成一分的畫、選、回來；觀察他能否用自己的話說出所選打法／技能和原分的關係。再找少量有全場對打經驗的較大孩子，看按需展開的深層內容是否有用。不要以點擊率或成人代操代替理解。
4. **內容校準。** 先以「受壓回深爭取回位」「短球打深後跟進」「斜線調動再變線」三個現有情境核對戰術圖、六項技能第一階示範與一句觀察重點。每個情境答清楚「何時用、希望換來什麼、這次練哪一點、什麼訊號要改打法」；由懂青少年網球教學的人檢查，不先新增模板數量或三階選擇器。
5. **放行／下一版。** 把真機及孩子發現寫回驗收表，阻斷修復後重跑完整回歸與 CI。只有 G3/G4 與資料風險處置可接受，才把版本定為 `0.3.0`、合併 `main`、核對 Pages `version.json`。下一版候選再考慮對手不同應變的少量分支；AI 自動建議、課程／打卡、雲同步、社區不在本輪。

若真機或孩子測試結果與目前設計相反，先調整最短路徑和內容，再談 v0.4；不要以已做的程式碼作為產品正確性的證據。
