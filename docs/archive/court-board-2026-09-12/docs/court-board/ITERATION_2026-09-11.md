# Court Canvas 画板迭代记录 — 2026-09-11

## 目标与发布边界

本轮接续实现 Theme 1 战术画板，重点是让用户从入口立刻开始画，并直接采用 Court Canvas 的拍次列、五工具列及整行播放层级。发布目标固定为独立测试仓库的 `preview/court-canvas-cad0d5f` 分支；不合并、不覆盖 `main`，当前公开预览提交 `951819474ace29c4c81fa5cf04e207aa8f885a68` 保留为本次发布的回滚点。

## 已完成

- `战术画板` 主入口优先恢复最新有效草稿；没有草稿时直接建立含我方、对手和网球的起始画板。
- 草稿／模板库、JSON 导入和纯空白画板移至次级文件入口；损坏的本机数据不会被静默覆盖。
- 底部直接采用 Court Canvas 的 `选择`、`球员`、`球路`、`跑位`、`标记` 五工具列及整行 `播放战术`；移除单一情境操作列与抽象的 `对象`、`添加` 两个入口。
- `球路` 与 `跑位` 点下即可在球场拖画，并保持当前工具；`球员` 提供我方、对手和网球，`标记` 保留目标、器材、文字、手绘及喂球路线。`选择` 继续提供对象列表与调整／删除的无障碍入口。
- 拍次列显示 Court Canvas 一致的 `下一拍`，读屏名称为 `新建下一拍`；播放导航仍在预览区，`沿用布置到下一拍` 继续表示复制标记的明确动作。
- 指针坐标统一换算为 Canvas 的 CSS 像素空间；拖动保留抓取偏移，5 CSS px 内的轻触不写历史，`pointercancel` 恢复提交前状态。
- `选择` 模式下的重叠对象优先命中路线控制柄；`球路`／`跑位` 模式会忽略既有控制柄并使用实际按下的相容对象，连续绘制不会误改路线起点。绘制完成保留新对象选择与当前绘制工具，用户可明确切回 `选择`。
- 编辑与预览模式分离。暂停、拖进度、逐拍及播完均停留在预览姿态，可继续或重播；明确完成后才返回编辑。
- 一次完整拖动只产生一条撤销记录；播放、选择和面板状态不进入保存文件或历史。
- Portal 内的球员、标记、文件、拍次、练习与对象面板保持 Theme 1 样式及 44px 点击区；关闭带输入框的面板会同步收起模拟键盘。所有画板面板关闭时把焦点还给触发按钮或仍存在的主要控件，选择放置／对象项目后聚焦画布；同类标记在对象列表中使用本地化编号区分。
- 非当前 FlowStack 页面会进入 `inert` / `aria-hidden` 状态，避免读屏重复遇到背后的战术列表；小目标区仍保留至少 44 × 44 CSS px 命中范围。
- 延续现有 Theme 1 的深绿球场、蓝红角色、亮色球路、虚线跑位、拍次轨及大号播放动作。

- 本机草稿依赖当前网站来源的浏览器储存，不是云同步；更换域名或设备需使用 JSON。
