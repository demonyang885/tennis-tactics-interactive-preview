# Court Canvas 画板迭代记录 — 2026-09-11

## 目标与发布边界

本轮在 Mac mini 接续实现 Theme 1 战术画板，重点是让用户从入口立刻开始画，并把高频操作压缩成对象优先的单一流程。发布目标固定为独立测试仓库的 `preview/court-canvas-cad0d5f` 分支；不合并、不覆盖 `main`，旧预览提交 `cad0d5f56f8acb085433aaf91761be7c28c900fa` 保留为回滚点。

## 已完成

- `战术画板` 主入口优先恢复最新有效草稿；没有草稿时直接建立含我方、对手和网球的起始画板。
- 草稿／模板库、JSON 导入和纯空白画板移至次级文件入口；损坏的本机数据不会被静默覆盖。
- 底部固定为拍次列、单一情境操作列，以及 `对象`、`添加`、`播放`。选球后画球路，选球员后画跑位；器材、文字、手绘与喂球收进添加面板。
- 拍次动作明确区分 `＋新增一拍`、播放 `下一拍` 与 `沿用布置到下一拍`。
- 指针坐标统一换算为 Canvas 的 CSS 像素空间；拖动保留抓取偏移，5 CSS px 内的轻触不写历史，`pointercancel` 恢复提交前状态。
- 重叠对象优先选中路线控制柄；画路线使用实际按下的相容对象；绘制完成自动回到选择并保留新对象选择。
- 编辑与预览模式分离。暂停、拖进度、逐拍及播完均停留在预览姿态，可继续或重播；明确完成后才返回编辑。
- 一次完整拖动只产生一条撤销记录；播放、选择和面板状态不进入保存文件或历史。
- Portal 内的添加、文件、拍次与对象面板恢复 Theme 1 样式及 44px 点击区；关闭带输入框的面板会同步收起模拟键盘。
- 非当前 FlowStack 页面会进入 `inert` / `aria-hidden` 状态，避免读屏重复遇到背后的战术列表；小目标区仍保留至少 44 × 44 CSS px 命中范围。
- 延续现有 Theme 1 的深绿球场、蓝红角色、亮色球路、虚线跑位、拍次轨及大号播放动作。

## 已知边界

- 本机草稿依赖当前网站来源的浏览器储存，不是云同步；更换域名或设备需使用 JSON。
- 已在桌面浏览器及手机外框模拟中验证主要操作；真实 iPhone／Android 的触控手感、本机储存限制、下载和系统分享仍需实机确认。
- PNG／JSON 文件权限取决于浏览器与系统；本轮未承诺 GIF／MP4、iCloud 或账号同步。
